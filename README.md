
# GemmaAssist 🚀
### Multimodal Agent Skill Standard for C++ & Diagram Intelligence (Powered by Gemma 4)
🌐 **Live Demo**: [https://gemma-multimodal-agent.vercel.app](https://gemma-multimodal-agent.vercel.app)
GemmaAssist is a high-performance developer tool designed for hackathons, leveraging Google's flagship **Gemma 4** models to perform dual-mode C++ code optimization and visual flowchart-to-code reconstruction.

---

## ✨ Key Features
- **Code / Prompt Mode**: Paste raw C++ logic to instantly receive Big-O time/space complexity analysis and production-ready refactored code.
- **Flowchart Vision Mode**: Upload diagrams or select preset flowcharts to translate visual logic trees directly into structured C++ programs.
- **Structured Code View**: Clean, readable output formatting with auto-wrapping to prevent horizontal scrolling and zero-latency copying.
- **Tactile UI & Audio Feedback**: Built with Vite, React, Tailwind CSS, and Web Audio API micro-interactions.
- **Dual Execution Engine**: Supports live Google GenAI SDK integration alongside a resilient local fallback for zero-downtime presentations.
